# 📚 SoftUni Python Courses – Exercise Solutions

Welcome! This repository contains my personal solutions to the exercises from several Python courses provided by [SoftUni](https://softuni.bg/). It's intended as a reference and portfolio of progress through the various levels of Python programming education.

## 🧠 Courses Covered

Below are the courses included in this repository, in the order they were taken:

1. **[Programming Basics with Python – March 2023](https://softuni.bg/trainings/4002/programming-basics-with-python-march-2023)**  
   Covers fundamental programming concepts such as variables, conditional statements, loops, and basic problem-solving.

2. **[Programming Fundamentals with Python – May 2023](https://softuni.bg/trainings/4097/programming-fundamentals-with-python-may-2023)**  
   Focuses on data types, lists, functions, dictionaries, and simple algorithms like text processing and lists manipulation.

3. **[Python Advanced – September 2023](https://softuni.bg/trainings/4232/python-advanced-september-2023)**  
   Introduces advanced Python features like comprehensions, tuples/sets, functional programming, file handling, and error handling.

4. **[Python OOP – October 2023](https://softuni.bg/trainings/4233/python-oop-october-2023)**  
   Covers Object-Oriented Programming including classes, inheritance, encapsulation, polymorphism, and SOLID principles.

5. **[Python ORM – June 2024](https://softuni.bg/trainings/4547/python-orm-june-2024)**  
   Introduces Object-Relational Mapping using Python, working with databases, SQLAlchemy, and creating structured, data-driven applications.


> Folder names may vary slightly depending on how the content is structured per course.
